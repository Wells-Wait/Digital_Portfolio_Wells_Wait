Screen

The screen is the main interface for both the IC and EV car displaying the state of both cars. The screen system comprices two section rev-lights and of course a screen. The rev-lights are the most importaint part for the drivers are they are fast to read and indicate shifitng, warnings, and on the EV derate. There is one screen per driver as well as screens for diagnostics so each subsytem has the information they need during testing.

The screen runs on a Pi using QT to handle the graphics. The screen gets car data therough shared memory Protobuf packets. The shared memory was developed by me to help connect the screen, VCU and the rest of the systems on the Pi. The screen collects the data in C++ checks warnings and dispalys everything to the drive.
